# verl Integration

Use the current [verl repository](https://github.com/verl-project/verl) and its maintained guides for environment setup and training:

1. Follow the [verl Quick Start](https://verl.readthedocs.io/en/latest/start/quickstart.html) to prepare and run training.
2. Follow the [RL-Insight integration guide](https://github.com/verl-project/verl/blob/main/docs/advance/rl_insight.md) to enable monitoring in that environment.

For RL-Insight service setup, see [Quick Start](../quick_start.md); for server and client options, see [Configuration](../configuration.md).

## Metrics
