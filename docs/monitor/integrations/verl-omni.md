# verl-omni Integration

Use the current [verl-omni repository](https://github.com/verl-project/verl-omni) and its maintained guides for environment setup and training:

1. Follow the [verl-omni Quick Start](https://verl-omni.readthedocs.io/en/latest/start/flowgrpo_quickstart.html) to prepare and run training.
2. Follow the [RL-Insight integration guide](https://github.com/verl-project/verl-omni/blob/main/docs/start/rl_insight.md) to enable monitoring in that environment.

For RL-Insight service setup, see [Quick Start](../quick_start.md); for server and client options, see [Configuration](../configuration.md).
